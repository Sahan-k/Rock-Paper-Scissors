# Rock-Paper-Scissors
A simple Rock Paper Scissors game built using HTML, CSS and JavaScript

## Features 
- Player vs Computer
- Random computer choice
- Display win, lose, or toe results
- Track Score
- Reset Score
- Emoji images for Rock, Paper, and Scissors

# Technology used 
- HTML
- CSS
- JavaScript
